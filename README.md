# Простой тг-бот: материалы за подписку

## Как это работает
- В `config.py` задаются материалы (`MATERIALS`) — каждый превращается в кнопку меню.
- При нажатии на кнопку бот вызывает Telegram API `get_chat_member` и смотрит статус пользователя в канале.
- Если статус `member` / `administrator` / `creator` — подписан, бот сразу присылает материал.
- Если нет — бот просит подписаться и показывает кнопку «Я подписался», которая просто повторяет ту же проверку.

Никакой БД не нужно: подписка не хранится нигде на стороне бота, каждый раз спрашивается напрямую у Telegram.

## Шаг 1. Подготовка бота и канала
1. Создай бота через [@BotFather](https://t.me/BotFather), получи токен.
2. Добавь бота **администратором** в свой канал (без этого `get_chat_member` не сработает).
3. Узнай ID канала: проще всего — сделать канал публичным и использовать его юзернейм (`@my_channel`), либо получить числовой ID через любого бота типа @userinfobot (для приватных каналов ID выглядит как `-1001234567890`).

## Шаг 2. Настройка материалов
Отредактируй `config.py`:
- замени тексты кнопок и содержимое материалов на свои (можно вставлять ссылки, файлы через `message.answer_document`, и т.д.).

## Шаг 3. Деплой на Railway
1. Залей эти файлы в репозиторий на GitHub.
2. На [railway.app](https://railway.app) создай новый проект → Deploy from GitHub repo.
3. В разделе Variables добавь:
   - `BOT_TOKEN` — токен от BotFather
   - `CHANNEL_ID` — юзернейм или числовой ID канала
   - `CHANNEL_URL` — публичная ссылка на канал (для кнопки "Подписаться")
4. Railway сам подхватит `Procfile` и запустит `python bot.py` как worker-процесс (без веб-порта — это нормально, боту он не нужен, он работает через long polling).
5. Готово — бот запущен и работает 24/7, пока сервис активен в Railway.

## Важно
- Не нужен вебхук/HTTPS-домен — используется polling, это самый простой вариант для такого бота.
- Supabase и другие БД не нужны, пока тебе не понадобится аналитика (кто и когда получил материал) — вот тогда можно добавить SQLite или Supabase отдельным шагом.
- Если бот пишет "chat not found" или ошибку проверки подписки — почти всегда причина в том, что бот не добавлен админом в канал.
